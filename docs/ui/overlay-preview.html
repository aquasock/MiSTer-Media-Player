One overlay for playback information and subtitles

Design preview only. The picture below is a layout background, not decoded video. The bar, palette, time-field order and pixel-font style come from the former DVD-era player.

Preview controls

Fields: elapsed / total / remaining, showing only HH:MM:SS. Unknown duration uses --:--:-- and a patterned track, with no percentage claim. Picture aspect changes leave the overlay fixed to the output screen. The subtitle-region guide is not subtitle playback; no subtitle loading, parsing or timing is implemented.

The prototype keeps controls visible for inspection. Hardware behavior is specified in the implementation plan, including the independent ten-second hide timer and frame-boundary publication.
